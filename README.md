# Protótipo Front-End Django - HTML

Protótipo feito para verificar as capacidades e possibilidades do framework Django e sua integração com o Backend feito em [FastAPI](https://github.com/G2454/Simple-SA-API)

## Instalação

Clone o repositório por meio do comando

```bash
git clone https://github.com/G2454/FrontEndPythonStreamlit.git
```
Vá para a raiz do repositório e configure o venv
```bash
python -m venv venv
```

Ative o venv por meio do seguinte comando:
```bash
venv\Scripts\activate
```
Caso isso não funcione, navegue até a pasta Script por meio do comando "cd" e apenas digite no seu terminal
```bash
activate.bat
```
Por fim, instale as dependências
```bash
pip install -r requirements.txt
```

## Uso

Para executar o projeto, vá para a pasta TestProject e execute o comando abaixo

```python
python manage.py runserver
```
Se tudo estiver certo, o projeto abrirá sozinho numa nova aba do seu navegador padrão.
